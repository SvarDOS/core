# CHOICE messages. Russian (CP866).

1.0:Ждёт, пока пользователь выберет один из вариантов.
1.1:CHOICE [/C[:]клавиши] [/N] [/S] [/T[:]c,nn] [текст]
1.2:/C[:]клавиши  Допустимые клавиши. По умолчанию:
1.3:/N             Не показывать клавиши и ?.
1.4:/S             Учитывать регистр.
1.5:/T[:]c,nn      Выбрать клавишу c через nn секунд.
1.6:текст          Показываемый текст.
1.7:ERRORLEVEL - позиция нажатой клавиши.
2.0:Неверный ключ. Ожидаемый вид:
2.1:неверный синтаксис /C. Ожидаемый вид: /C[:]клавиши
2.2:неверный синтаксис таймаута. Ожидаемый вид: Tc,nn или T:c,nn
2.3:клавиша таймаута не входит в список.
2.4:допускается только одна строка. Ожидаемый вид:

# default keys (uppercased on screen unless /S is given)
3.0:дн
