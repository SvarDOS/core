# CHOICE messages. French (CP850).

1.0:Attend que l'utilisateur choisisse une des réponses proposées.
1.1:CHOICE [/C[:]touches] [/N] [/S] [/T[:]c,nn] [texte]
1.2:/C[:]touches  Touches acceptées. Par défaut :
1.3:/N             Ne pas afficher les touches ni le ?.
1.4:/S             Distinguer les majuscules.
1.5:/T[:]c,nn      Choisir la touche c après nn secondes.
1.6:texte          Texte à afficher.
1.7:ERRORLEVEL est la position de la touche pressée.
2.0:Paramètre invalide. Forme attendue :
2.1:syntaxe /C invalide. Forme attendue : /C[:]touches
2.2:syntaxe de délai incorrecte. Forme attendue : Tc,nn ou T:c,nn
2.3:la touche par défaut n'est pas dans la liste.
2.4:un seul texte est permis. Forme attendue :

# default keys (uppercased on screen unless /S is given)
3.0:on
