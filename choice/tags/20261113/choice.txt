
                                 SVARDOS CHOICE

CHOICE waits until the user presses one of a set of keys, then returns the
position of that key in ERRORLEVEL. Messages follow the LANG variable.


### USAGE ####################################################################

  CHOICE [/C[:]keys] [/N] [/S] [/T[:]c,nn] [text]

  /C[:]keys   Keys that are accepted. Default is YN (or the equivalent
              letters of the loaded language, for example TN when LANG=PL).
  /N          Do not display the key list and the question mark.
  /S          Case sensitive. Without /S, keys are shown in uppercase and
              either case is accepted.
  /T[:]c,nn   After nn seconds (0 to 99) behave as if c had been pressed.
              nn = 0 selects c immediately. c must be one of the keys.
  text        Prompt printed before the key list. Quote it if it contains
              a slash. Only one prompt is allowed.

  CHOICE /?   prints the help screen.


### ERRORLEVEL ###############################################################

  1       first key
  2       second key
  ...
  255     bad command line, or /?
  0       Ctrl+C or Ctrl+Break (DOS aborts the program)

A key that is not in the list beeps and is ignored. The accepted key is
echoed, followed by a new line.


### LANGUAGE #################################################################

  SET LANG=PL

looks for CHOICE.LNG next to CHOICE.COM. Unknown or missing translations stay
in English, which is stored in the program.
